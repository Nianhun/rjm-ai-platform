# 瑞吉明配方 AI 初版验收说明

## 演示目标

本初版用于演示“保湿配方”闭环：AI 根据原料属性、关系图谱和历史反馈生成候选配方 list，配方工程师筛选后进入实验，实验反馈再回到系统形成学习进化，并继续进入采购建议。

## 演示路径

1. 启动本地原型栈。
2. 打开工程师工作台。
3. 输入目标功效：`保湿`。
4. 查看 3 个候选配方、评分、风险提示和证据 ID。
5. 点击证据 ID 查看来源。
6. 记录工程师筛选意见。
7. 创建实验批次并提交一次通过的实验反馈。
8. 查看反馈影响报告和学习权重解释。
9. 重新推荐，观察学习进化后的评分或排序变化。
10. 进入采购建议，查看原料供应商 SKU 或缺口。

## 可执行验收

脚本会生成：

该 JSON 包含推荐、工程师筛选、实验反馈、学习进化和采购建议的验收摘要。

## 当前能做什么

- 给出保湿候选配方 list。
- 保留配方原料、建议比例、评分、风险和证据 ID。
- 记录工程师筛选、实验反馈和反馈影响。
- 根据实验反馈调整后续推荐权重。
- 根据配方原料生成采购建议。
- 通过 Java 管理系统提供 API 和工程师工作台。

## 当前不能做什么

- 不能替代配方工程师的经验判断。
- 不能替代真实实验、稳定性测试、功效测试、法规合规和安全评估。
- 不能把 Yuxi 产品共现关系直接视为实验验证的协同关系。
- 不能在未配置内网边界和 token gate 时公开配方比例、供应商价格、实验结论或采购状态。
